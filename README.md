# Game Baithak frontend (bluff-frontend)

Mobile-first React app for **Game Baithak**, a home for 2–4 player online games with friends: Ludo, Saanp Seedhi, Raja Mantri Chor Sipahi, Bluff, Crazy 7, Rang, Chess, Carrom, Darts, Dots and Boxes, Colour Wars, Five in a Row, Ultimate Tic-Tac-Toe, Word Grid Hunt, Sea Battle, Bomb Pass, Fruit Slice Duel and Spike Attack (18 games). The repo keeps its old name. Connects to `bluff-backend` over Socket.IO and reads every move aloud with the phone's built-in voice.

## Run locally

Start the backend first (`npm run dev` in `bluff-backend`), then:

```bash
npm install
npm run dev      # http://localhost:5173
```

Open it in several browser tabs (or a normal + private window) to play as different people. Each tab is its own player.

## Play on real phones over home Wi-Fi

1. Mac and phones on the same Wi-Fi.
2. `npm run dev` prints a **Network** address, e.g. `http://192.168.1.5:5173`. Open that on each phone.
3. The app finds the backend on port 3001 of the same Mac automatically. If macOS asks whether `node` may accept incoming connections, allow it.

## Deploy on Vercel (free)

1. Push this folder to its own GitHub repo.
2. Vercel → **Add New → Project** → import the repo. Framework **Vite** is detected (build `npm run build`, output `dist`).
3. Environment variable `VITE_SERVER_URL` = your Render URL, e.g. `https://bluff-backend.onrender.com`. Deploy.
4. Put the Vercel URL into the backend's `CLIENT_ORIGIN` on Render and redeploy it.

`VITE_SERVER_URL` is baked in at build time, so redeploy the frontend after changing it.

`vercel.json` adds security headers (Content-Security-Policy, no framing, nosniff, Referrer-Policy, Permissions-Policy). Its `connect-src` names the Render backend (`https://` and `wss://`): **if the backend URL changes, update it there too**, or the app can't reach the server.

## Invite links

- The lobby has **WhatsApp**, **Share…** (phone share sheet) and **Copy**. They send `Join my Game Baithak room 🎲 Room code: ABCD` plus `https://<site>/?room=ABCD`.
- Opening the link joins that room directly: a phone that already had a seat there gets it back, a phone with a saved name joins at once, and a new phone only types a name and taps **Join room ABCD**.
- The `?room=` part is removed from the address bar once inside, so reloading or leaving never re-joins by itself.

## Accounts

- When the backend has a database, the home screen offers **Log in / Sign up**; otherwise only guest play is shown.
- Logged-in players play under their account name; wins, losses, stats and coins are saved. **My stats** shows lifetime numbers and the last 10 games.
- Admins get an **Admin** button: a **Guest play** On/Off switch (asks first; when off, guests see "Log in to play" instead of Create/Join), search all users, give or take coins (with a reason), make someone admin.
- The login token is kept in the browser and sent as `Authorization: Bearer …` to the API and in the socket handshake.

### How to add a new game (frontend)

1. Backend first: add the kind to `GameKind`, `PLUGGED_GAMES`, a `GAME_CATALOG` entry (options), its `PluggedView` / `PluggedMove` variants and view types in `bluff-backend/src/types.ts`, then copy the file here (keep line 1).
2. Make `src/games/<kind>/` with a table component taking `TableProps` (`view`, `actions`, `bubbles`, `auth`, `notes`) that reads `view.plugged` and sends moves with `actions.gameMove({ kind, move })`, and an optional `Rules` component (`{ config }`).
3. Register both in `PLUGGED` in `src/games/registry.tsx`. That's all the routing: `App` sends every `isPlugged` game to `PluggedTable`, the handshake already sends `PLUGGED_GAMES`, the lobby draws the catalog options (respecting `when`), the home grid and profile read the catalog.
4. Reuse the shared pieces: `Seat`/`SeatSheet` (throws, bubbles, voice, turn timer), `TableInfo`, `GameOver`, `useTableFx`, `confetti`, `LudoMenus`-style menu. New styles in their own `styles/land-<game>*.css`; animate only transform/opacity and respect `reducedMotion()`.
5. Add a lesson (or a rules sheet like `LudoLesson`) by branching in `TutorialPage`, a Rules page section, Hindi lines (`lib/i18n/hi.<game>.ts`, listed in `hi.ts`) and a map row in `CLAUDE.md`.

## Crazy 7 (second game)

- **Pick the game:** at the top of the lobby the host chooses 🃏 Bluff (default) or 7️⃣ Crazy 7; the settings below follow the game and everyone else sees them as chips. Rooms, seats (2–5), bots, coins, invites, watching and host tools are shared.
- **Settings:** coins at stake, cards each (5 or 7), picks per turn (1–7), Stack 7s (On/Off), 1 or 2 decks.
- **Play:** match the top card's suit or number. Cards you can play lift and glow green, the rest fade; one tap plays a card. The deck glows when you may pick (tap it, or **Pick a card · n left**); **Pass** appears only when the room allows more than 1 pick a turn, after you've picked: it stops picking early. At the limit you must play a card that fits. With nothing to match, the first card is picked for you.
- **7s:** a big red banner shows the waiting pick ("Pick 4 or play a 7!"); only 7s glow; **Pick N** (or the deck, whose tip then says Pick N) takes it. With Stack 7s on, everyone hit by a 7 taps Pick N themselves, so nobody can tell who holds a 7; with it off the pick is taken for them.
- **📢 Last card** shows on your turn with 2 cards ("say it, then play") and right after you're down to 1; it turns red and shakes ("Say LAST CARD now!") while you're at risk. You're caught only when another player plays, picks or passes before you say it; if the turn just comes back to you, you can still say it or play your last card. Caught: next turn you pick 1 (plus any waiting 7) and miss it, and your hand shows 🙊 Missed. Seats show 📢, a red **1 card!** and 🙊. Bots wait at least 3.5 s when a person is at risk, and sometimes forget to say it themselves.
- **Table:** seats start from the player after you and that seat is tagged **next**; under the pile "Ravi played 7♠"; tapping a card off-turn says "Wait for your turn". A reload or rejoin mid-game doesn't replay the deal. If the host is offline anyone can Stop the game from ⋯.
- **Motion and sound:** the played card flies face up to the pile and lands (a 7 sends out a red shock ring and its own sting), picked cards fly from the deck, a bell rings for any Last card call, a buzz for a catch, a riffle when the pile is shuffled back in, and the winner gets confetti.
- If nobody can play and nothing is left to pick, the fewest cards wins. Leaving mid-game is a loss; in a 2-player game the other wins.
- Game over uses the same screen: the winner wins, everyone else lost (with cards left).

## Landscape and the 3D table

- **Always sideways on phones, no rotating needed:** a web page can't force a phone into landscape (iPhone never allows it; Android only in full screen), so on touch phones and tablets the app runs inside a small shell (`lib/landscapeShell.ts`, chosen in `main.tsx`; the app itself boots from `boot.tsx`). While the phone is upright, even with the rotation lock on, the shell turns the game's frame 90° and sizes it so the game always sees a landscape screen: you just hold the phone sideways, like Free Fire or Uno. On Android the motion sensor tells which edge is down, so it's never upside down; iPhone assumes the left edge is down. When the phone really is sideways, the frame simply fills the screen. Invite links (`?room=`) are passed to the game and dropped from the shell's address. Any touch screen counts (`navigator.maxTouchPoints`, `any-pointer: coarse`), so an iPad with a keyboard and trackpad or a tablet with a pen gets the shell too instead of the narrow portrait layout. The shell refits whenever its box changes size (`ResizeObserver`, and again for 0.8 s after a turn), because tablets report the new size at different moments while turning. **No `screen.orientation.lock` anywhere:** it only holds in full screen, so leaving full screen (back gesture, switching apps) let an app installed with the old portrait setting snap upright, and the next tap locked it again; that flip-flop, with a blank moment at each turn, is what players saw. Landscape now comes only from turning the frame, or from the manifest once Chrome has updated the installed app (it does that only with every window closed, charging and on Wi-Fi; `about://webapks` → Update forces it, or remove and re-add the app). The upside-down turn (Android sensor) needs the phone clearly on its other side (|gamma| > 68°, |beta| < 50°) for 0.7 s, so tilting while playing never flips it. Laptops and desktops (no touch) run the app directly; `?flat` skips the shell for testing. `vercel.json` allows framing by the site itself only (`frame-ancestors 'self'`, `X-Frame-Options: SAMEORIGIN`). The installed app asks for landscape (`orientation` in `public/manifest.webmanifest`). `components/RotateGate.tsx` ("Turn your phone") is now only a fallback for a touch screen held upright outside the shell.
- **The phone's bars lie over the game** (`held` in `lib/landscapeShell.ts`): pulling down the time and notifications or the back-gesture bar shrinks the page for a moment; the game keeps its size and the bars just lie over it, like a native game. More room (full screen on, or turning the phone) is taken at once; less room only counts if it's still there after 2.6 s (full screen really ended).
- **No status bar, like a phone game** (`autoFullscreen` in `lib/orientation.ts`, called from `boot.tsx`): on touch phones the first tap goes full screen (browsers allow it only after a tap), hiding the status bar and the browser bar and locking landscape; a swipe from the top shows them for a moment, and if the player leaves full screen the next tap brings it back. Inside the shell the game asks the shell page to do it (`SHELL_FS_ON`). The installed app opens full screen (`display: fullscreen` in the manifest; `isInstalled` and `isStandalone` count it). iPhone has no full screen for web pages, so its status bar stays; there is no ⛶ button any more.
- **The 3D table** (`components/TableScene.tsx`, `components/Table3D.tsx`, `styles/land-world.css`): one real 3D world. A table plane tilted away from you (a rim with real thickness, a floor shadow, the felt in the player's own table colours, a lamp's pool of light; a gold rim on ranked tables) holds everything on the table: `<OnTable x y stand>` places an item in % of the table, lying on the felt or standing up facing you. Opponents stand at the far rail as avatars with a name plate (`seatSpots`), their face-down cards lie in a fan on the felt in front of them (`OppCards`), and whoever's turn it is gets a gold pool of light there. Bluff's pile is a real stack whose paper layers grow with its cards (`Pile3D`), with the round's sign standing beside it. Anything lying on the felt sits at least 2px above it (flush layers z-fight and vanish).
- **A clean table, one info place** (`components/TableInfo.tsx`): the ☰ button with the room code (top left; a purple badge shows the secret mission's progress) opens a panel with the secret mission, my own counts (peeks, shields, calls left, points…), this table's rules (`tableRules`), tips and "Just now" (the last moves). The table itself shows only the players, the cards and what you can tap. In a landscape game, notices for plays, passes, rounds, calls and chat don't pop up (`QUIET_IN_GAME` in `App.tsx`); they're in "Just now". Errors and big moments still pop up.
- **Your hand** (`components/FanHand.tsx`): centred at the bottom with equal room on both sides (`--side-w`); in Bluff, Pass sits in the bottom left corner and Play / call a rank in the bottom right with BLUFF! above it, so buttons never push the cards. Cards fan in an arc; a picked card comes up out of the fan towards you (3D lift), keeping the tap order. When the hand needs 2 or more rows, a picked card only nudges up inside its own row with a gold outline and its number, so it never covers the rows behind, and back rows leave each corner readable and tappable. YOUR TURN (with the timer) and Clear sit in the empty bottom-left corner above Pass, never on the cards, and the table's rim glows gold while it's my turn. A hand too big for one arc (2 decks) folds into **one stack per rank** in Bluff (13 stacks at most, so it always fits): tap a stack for a **how many?** chooser (1, 2, … All, None; it sits above everything near the hand, so every number takes the tap), a single card toggles at once; a picked stack shows ✓ and its count on its visible left edge; **▦ Stacks / 🂠 Fan** switches by hand and is remembered on the phone.
- **2v2 on the 3D table** (Bluff and Rang): everyone sits in play order starting after me, so my partner is straight across at the top centre, opponents left and right. My partner's cards are held up face up in front of them in a 3D fan (card edges, gloss and shadow, a pool of the team colour on the felt; `PartnerFan` in `Table3D.tsx`): in Bluff one card per rank, A to K, with ×N counts (`PartnerCards`, from `RoomView.partnerHand`); in Rang the same colour and value grouped with ×N, sorted by colour then value (from `RangView.partner`); a hand too big to show each face (more than ~11 kinds) puts each card's sign in a chip of its colour above it. Counts always sit above the card's top corner, the one spot a fan never covers. Only partners get these. In the room, a player outside the four team slots (a 5th) still shows at the rail so the host can remove them.
- **Direction of play** (`RangArrows` in `RangTable3D.tsx`, Rang and Crazy 7 with power cards): two arrowheads glide round a dashed oval on the felt, chasing each other the way play goes, with the dashes flowing (SVG `animateMotion`, 9 s a lap); a Reverse mirrors them. Still under reduced motion.
- **Uno-style moments** (`components/TableFx.tsx`, `styles/table-fx.css`, used by Rang and Crazy 7): a red ⊘ SKIP! lands on the skipped player (Crazy 7's 8: on the pile), big gold arrows spin for a reverse (A), a +2 / +4 slams onto the pile showing the running total when they stack (a +4 shakes the table) and a +N lands on whoever has to pick, a wild's four-colour wheel spins and the chosen colour floods out with its name (Crazy 7's J: the named suit), LAST CARD! bursts from whoever says it and CAUGHT! stamps on whoever forgot. Each has its own sound (`sfx.skip`, `sfx.reverse`, `sfx.wild`). Effects sit above the table but below sheets (z-index 45) and turn off with reduced motion.
- **Cards in flight** (`components/FlyingCards.tsx`): a card from my hand starts at its real size where it sat (`froms` / `startWidth`; `lib/cardRects.ts` remembers where each card sat, by `data-card`, for Crazy 7 and Rang), lifts out of the hand, travels an even arc and shrinks to the pile's size as it lands lying at the table's lean (`onTable`). My own Bluff cards lift out face up, flip over in place (edge-on half way, back up), then fly face down onto the pile (`faces`, `froms`; cards carry `data-card`). Every keyframe uses the same transform steps in the same order (`pose` in `FlyingCards.tsx`): a mismatched list is blended as a matrix, which mirrors the card at 180° instead of turning it over. Crazy 7 and Rang add rows instead. `fanLayout` is shared with Rang's hand. **Picked cards** (`lib/arrivals.ts`, Crazy 7 and Rang): each new card's place in my hand stays empty (`arrivingCss`) while it leaves the deck face down, arcs up, turns face up in the air and lands exactly on that place (`arrive`), several picks one after another; other players' picks stay in sight all the way to their seat (`vanish`) and only settle in at the end. **2v2 Rang partner** (`PartnerRows` in `Table3D.tsx`): a fixed box (`ROWS_WIDTH`) of straight rows sorted by colour, one card per colour and value; a chip on each card's visible left edge shows its sign and ×N, cards pack closer as the hand grows and wrap onto more rows (`partnerRows`), so a 50-card hand stays between the seats. **Rang running out of cards**: a +2/+4 bigger than what's left picks only what there is; with nothing left the felt sign, status, deck ("Empty · no cards left", tip Miss turn) and button say the turn is missed, and the seat shows NO CARDS LEFT. Crazy 7 does the same for a 7's pick (`shortPick` in `Crazy7Table.tsx`, `refill` on `Deck3D`).
- **The room before a game** (`components/LobbyRoom.tsx`, `LobbySettings.tsx`): sits at the same 3D table as the game. Players stand at the far rail, open seats glow with a "+" (the host adds a bot or invites from them), you sit at the near side, the table's settings show as one sign on the felt (host: ⚙ Settings opens the settings drawer; others open it read-only), and a dock holds Leave, Invite, Play/Watch and Start / I'm ready.
- **Home** is a game menu: logo and one ▶ Play (create a room or join with a code), an "Online now" list of friends on the left, the green online count by the profile, and a dock of round buttons for everything else.
- **First screen**: on an upright touch phone even the very first intro (in `index.html`, before any code runs) is drawn sideways by CSS, and the shell keeps it until the game inside has loaded, so there's never an upright or blank moment.
- **My plays don't wait for the server** (`play` in `Table.tsx`, `playNow` in `Crazy7Table.tsx` and `RangTable.tsx`): the rank picker closes and my cards fly the moment I tap; they're hidden from my hand (`sending`) while the server confirms, and the server's own move doesn't fly them again (`myPlay.flown`, `flown`). If the server refuses, the cards come back (still picked in Bluff) and the error shows. Every move still takes one trip to the server (Render's Oregon region, ~350–400 ms from India), which is what the rest of the lag is.
- **Back with full screen** (`autoFullscreen` in `lib/orientation.ts`): on Android the back button first only leaves full screen, so it seemed to need two presses. A full-screen exit we didn't ask for, while the app is still in front a moment later, now counts as that back press (`stepBack` in `lib/back.ts`). The installed app never asks for full screen (its manifest already opens it full screen), so back works there directly.
- **Keeping it smooth on phones and big tablets**: every 3D-placed element is a layer the phone composites each frame, and on a high-res tablet (e.g. a 12.7" 2944x1840 Lenovo) each full-table layer is a ~3000x2200 picture; six of them ran the graphics chip out of memory, so halves of the screen blinked and changed colour. The tilted plane is now one layer: the rim's thickness is a shadow under the rail, the floor shadow lies flat outside the 3D space, and the felt's grain is a light pattern instead of a noise image. Bars over the table (`.room-dock`, top bar, action buttons) get their own small layer so redrawing the table never flickers them. Stacks draw at most 6 paper layers spread over the same height (`paperSteps` in `Table3D.tsx`). At the table and in the room there's no frosted-glass blur and the home screen's drifting light is switched off (`land-world.css`, end). Animate only `transform` and `opacity`. The socket connects over WebSocket straight away (`transports`, `tryAllTransports` in `lib/socket.ts`).
- **Table looks on the 3D table**: the felt shows the player's own table theme with its art (`styles/land-felt-art.css`, made from the `:root[data-table='…'] body::before` blocks in `looks.css`; re-make it when a table's art changes), each seat is a small card in that player's own table look (`--seat-bg`), and the room's bottom bar follows the table colours.
- **Panels over the table** are solid with a darker screen behind (`land-world.css`), and on screens 700px tall or more (tablets, laptops) they grow 1.3–1.45x instead of staying phone-sized; a panel opened from inside another isn't grown twice.
- **Every screen** has a landscape layout in its own stylesheet (`styles/land-*.css`, imported last, all inside `@media (orientation: landscape)`): home, lobby, pages, sheets and results. Sizes use `--u` (1% of the screen height) from `styles/landscape.css`.
- Checking sizes on a computer: the browser's device toolbar at 844x390 (iPhone 14), 667x375 (iPhone SE) and 915x412 (Android).

## Chat, watching and awards

- **🎧 Live voice** (`components/LiveVoice.tsx`, `lib/liveVoice.ts`): 🔊 hear and 🎙️ talk switches that say ON / OFF (game top bar; "Hear · On" / "Mic · Off" in the lobby row); every player's box shows their mic (green 🎙️ on, crossed out off, ⚠️ can't hear them yet, from `PublicPlayer.mic`). The old 7-second voice notes are gone. Live voice is for logged-in seated players while the host's voice switch is on; watchers and guests never. Phones connect directly (WebRTC mesh, one offer and one answer per pair through `rtc:signal`, all routes in one message); the mic switches on and off without reconnecting. No popups: a seat shows 🎧 (in voice) or 🔇 (can't hear them yet), dropped connections retry quietly (2 s doubling to 30 s), and at most one line per room says this network can't connect.
- **💬 Quick chat** (lobby and table): 8 emoji reactions and 26 quick messages float up on every screen with the sender's name (never the top banner). Edit the lists in `src/types.ts` (and the same file in the backend).
- **Watch mode:** joining when 5 are seated, or mid-game once the host lets you in, makes you a watcher: you see the table, hear the voice and can chat; you get a seat in the next game. In the lobby anyone can switch **🎮 Playing / 👀 Watching**; a chosen watcher keeps watching until they switch back. The host can also move anyone from their player card (Move to watching / playing).
  - Watchers see the real cards of each play face up (green = matches the claim, red = bluff).
  - Watchers see one player's hand at a time: it follows whoever's turn it is, or tap a player to stick to them ("Follow turn" goes back).
  - Only watchers' phones receive these cards; seated players never get anyone else's hand.
- **Awards** on the Game over screen: Biggest liar, Smoothest liar, Best detective, Trust issues, Card collector. The voice also announces the Biggest liar.

## Install as an app

Bluff is a Progressive Web App: friends install it from the website, free, with no app store.

- **Android (Chrome):** tap **Install** on the home screen card, or browser menu ⋮ → **Install app**.
- **iPhone (Safari):** Share ⬆ → **Add to Home Screen** → **Add**. The Install card shows these steps.
- It then opens full screen from its own icon and updates itself after every Vercel deploy.
- `public/sw.js` loads fresh files first and keeps a copy only so the app can open without internet. `public/icons/app-icon.svg` is the source of the PNG icons. `public/icons/badge-96.png` is the notification's status-bar icon: white on transparent, because Android uses only its shape.
- Install **before** joining a game: on iPhone the installed app has its own storage, so a seat taken in Safari isn't carried over.

## Voice

- Uses the browser's speech feature: no audio files, no paid service.
- **Girl voice is the default.** Each phone can switch Girl / Boy in the lobby; the choice is remembered on that phone and the voice name is shown under it.
- Browsers don't report a voice's gender, so the app matches known voice names (Samantha, Heera, Google UK English Female…). Android voice names don't say the gender, so there it uses the phone's Indian-English voice with a slightly higher pitch; for a different voice, change the voice in Android's text-to-speech settings.
- iPhone allows speech only after the first tap; any tap in the app unlocks it. "Test" in the lobby checks it.
- If nothing is heard on iPhone, check the silent switch and volume. 🔊 / 🔇 in the game header turns the voice on or off for that phone.
